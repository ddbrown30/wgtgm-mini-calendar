# Mini Calendar
Mini Calendar is a compact, lightweight calendar for Foundry VTT. It provides a streamlined interface for managing time, dates, and notes without taking up valuable screen space. It offers two view modes: an ultra-compact and a month calendar view.

## Installation

1. In Foundry, navigate to the Add-on Modules tab.  
2. Click Install Module.  
3. Either search for "Mini Calendar" or  paste the manifest URL:   
   [https://github.com/xthesaintx/wgtgm-mini-calendar/releases/latest/download/module.json](https://github.com/xthesaintx/wgtgm-mini-calendar/releases/latest/download/module.json)
4. Click Install.  
5. Enable the module in your world.
